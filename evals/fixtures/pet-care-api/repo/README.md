# pet-care-api

Sistema de turnos para una veterinaria y peluquería de mascotas.
Los dueños registran sus mascotas y reservan turnos para servicios
(baño, corte, consulta). Backend FastAPI + PostgreSQL, frontend React.

Fixture de Atlify: tiene errores plantados a propósito.
